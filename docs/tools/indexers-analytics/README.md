# Indexers & Analytics

Indexing and analytics tools let you query and analyze on-chain data on Gnosis Chain through APIs and GraphQL, instead of scanning blocks yourself.

**Choosing:** building a custom API over your own contracts → [The Graph](/tools/indexers-analytics/the-graph), [SubQuery](/tools/indexers-analytics/subquery) or [Envio](/tools/indexers-analytics/envio); ready-made REST APIs for wallet, token and NFT data → [Moralis](/tools/indexers-analytics/moralis) or [GoldRush](/tools/indexers-analytics/covalent); SQL and dashboards over decoded chain data → [Dune](/tools/indexers-analytics/dune).

| Provider | What it does | Networks |
| --- | --- | --- |
| [The Graph](/tools/indexers-analytics/the-graph) | Decentralized protocol for indexing and querying chain data | Gnosis · Ethereum |
| [SubQuery](/tools/indexers-analytics/subquery) | Open-source data indexer with custom APIs | Gnosis · Ethereum |
| [Envio](/tools/indexers-analytics/envio) | Fast, flexible indexing for real-time and historical EVM data | Gnosis · Ethereum |
| [Moralis](/tools/indexers-analytics/moralis) | Enterprise-grade APIs for wallet, token and NFT data | Gnosis · Ethereum |
| [GoldRush (Covalent)](/tools/indexers-analytics/covalent) | Comprehensive blockchain data API suite | Gnosis · Ethereum |
| [Dune](/tools/indexers-analytics/dune) | On-chain data platform and dashboards | Gnosis · Ethereum |
