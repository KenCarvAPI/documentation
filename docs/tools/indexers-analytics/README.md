# Indexers & Analytics

Indexing and analytics tools let you query and analyze on-chain data on Gnosis Chain through APIs and GraphQL, instead of scanning blocks yourself.

- [The Graph](/tools/indexers-analytics/the-graph) - decentralized protocol for indexing and querying chain data.
- [SubQuery](/tools/indexers-analytics/subquery) - open-source data indexer with custom APIs.
- [Envio](/tools/indexers-analytics/envio) - fast, flexible indexing solution for real-time and historical EVM data.
- [Moralis](/tools/indexers-analytics/moralis) - enterprise-grade APIs for wallet, token and NFT data.
- [GoldRush - powered by Covalent](/tools/indexers-analytics/covalent) - comprehensive blockchain data API suite.
- [Dune](/tools/indexers-analytics/dune) - on-chain data platform and dashboards.
